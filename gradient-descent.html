About the surface & update rules

The random surface joins alternating wells and ridges with cosine segments, bends the valley, then rotates it in the x–y plane. It has exactly the chosen number of non-global local minima and one global minimum with loss 0. Presets instead use the formulas shown in their descriptions, with fixed geometry and minimum counts. The saddle is unbounded below; its origin is a stationary point, not a minimum.

The analytic gradient of the actual loss drives optimization. Logarithmic display height only makes the landscape easier to see; negative-valued surfaces are shifted by the lowest sampled mesh value before taking the logarithm. Readouts and loss history retain the original, unshifted values.

SGD uses the exact gradient here, without minibatch noise. Momentum uses an accumulated gradient; Adam uses bias-corrected first and second moments; RMSprop uses an exponential average of squared gradients. No weight decay is applied. Convergence requires both gradient norm and step length below 0.001 for five consecutive steps.

Muon operates on matrix-valued parameters, so it is omitted from this two-coordinate experiment. Algorithm references: SGD, Adam, RMSprop, Muon.
